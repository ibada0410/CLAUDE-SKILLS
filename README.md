# Claude Skills

A collection of **117 Claude Code skills** organised into 10 categories. Each skill is a folder with a `SKILL.md`.

## Install

Copy the skill folders you want into `~/.claude/skills/` (Windows: `%USERPROFILE%/.claude/skills/`), then start a new Claude Code session.
