# Claude Skills

A collection of **1419 Claude Code skills** organised into 18 category folders. Each skill is a folder containing a `SKILL.md`. Every category folder has its own README listing its skills with a one-line description.

## Install

Copy the skill folders you want into `~/.claude/skills/` (Windows: `%USERPROFILE%/.claude/skills/`), then start a new Claude Code session. Installing everything at once makes each session load a very long skill list, so pick the categories you need.

## Notes

- **Prefixed names.** `alireza-`, `composio-` and `jeff-` mark a skill whose name clashed with another skill that has different content.
- **App automations.** The `*-automation` skills in `App-Automations-Composio/` need a Composio (Rube MCP) connection and an authorised account for each app.
